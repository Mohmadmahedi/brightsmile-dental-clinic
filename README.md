# BrightSmile Dental Clinic 🦷✨

A modern, responsive, single-page website for **BrightSmile Dental Clinic** designed for digital agency portfolio presentation.

---

## 🌟 Features

- **Modern Aesthetic**: Clean medical palette (Teal `#0EA5A4`, Soft Blue `#E6F6F6`, Dark Navy `#0F2A3D`, Amber Accent `#F59E0B`).
- **Interactive Before & After Slider**: Drag/touch comparison slider with multiple procedure case studies.
- **Conversion Focused**: Clear "Book Free Checkup" calls-to-action throughout.
- **6 Comprehensive Services**: Checkup & Cleaning, Teeth Whitening, Root Canal, Aligners, Implants, Pediatric Dentistry.
- **Patient Booking Form**: Client-side validation with real-time feedback and booking confirmation screen.
- **FAQ Accordion**: 5 common patient questions with smooth collapse/expand and ARIA accessibility.
- **Mobile First**:
  - Slide-out mobile navigation drawer
  - Sticky mobile bottom bar with quick Call & Book buttons
  - Floating WhatsApp launcher
  - 100% responsive fluid grid down to 320px screens
- **Zero Dependencies**: Pure HTML, Vanilla CSS, and JavaScript. No build step required.

---

## 🚀 Live Preview / Local Run

Simply open `index.html` in any web browser, or serve it with Python:

```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
